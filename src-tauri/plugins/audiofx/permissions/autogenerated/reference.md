## Default Permission

Everything the visualiser and equaliser need.

#### This default permission set includes the following:

- `allow-state`
- `allow-check-permissions`
- `allow-request-permissions`
- `allow-visualizer-start`
- `allow-visualizer-stop`
- `allow-visualizer-frame`
- `allow-eq-set`
