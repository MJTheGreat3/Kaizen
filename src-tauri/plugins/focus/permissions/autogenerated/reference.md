## Default Permission

Everything the focus timer needs.

#### This default permission set includes the following:

- `allow-start`
- `allow-pause`
- `allow-resume`
- `allow-stop`
- `allow-drain-events`
- `allow-access`
- `allow-open-usage-settings`
- `allow-open-dnd-settings`
